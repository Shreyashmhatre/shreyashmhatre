## Featured project

### [ZeroTrustAI · API Security Platform](https://github.com/Shreyashmhatre/Mega-Project)

An academic prototype that puts a security gateway in front of a demo API, evaluates
requests, and records enforcement decisions in a live SecOps dashboard.

- **Stack:** Python, FastAPI, Redis, PostgreSQL, Scikit-learn, Docker, JavaScript.
- **Implemented:** JWT checks, object ownership/role enforcement, rate limits,
  temporary quarantine, numeric request features, and Isolation Forest inference.
- **Status:** Working prototype with automated tests. The ML baseline uses synthetic
  data; real MFA, an autoencoder, and representative detection evaluation are still planned.
